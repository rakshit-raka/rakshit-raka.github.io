## Run it locally

1. Download or clone this repository.
2. Open `index.html` in any web browser.

## Deploy with GitHub Pages

1. Create a public repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html` and this `README.md` to the repository.
3. Go to **Settings > Pages**, set the source to **Deploy from a branch**, choose the `main` branch and the `/ (root)` folder, then click **Save**.
4. After a minute or two, the site is live at `https://YOUR-USERNAME.github.io`.
